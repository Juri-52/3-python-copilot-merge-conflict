# 動作の確認

main.pyがあるフォルダーで、仮想環境のPythonを使います。

```bash
python -m pytest -q
```

配布時のmainには五つのテストがあります。Productの表示、JSONの読み込み、一覧の順番、一覧のコピー、商品がない場合を確認します。

## 新しい機能を追加するとき

新しい条件に合うテストを追加します。既存テストの期待値を、誤った実装に合わせて書き換えないでください。pytestの結果と、メニューから操作した結果の両方を確認します。料金や在庫数はdocs/data.mdと比較します。

## 手動で確認する項目

- 1で商品10件を表示できる。
- 繰り返し1を選んでも、件数と順番が変わらない。
- 0で終了できる。
- メニューにない値を入力しても、案内の後に続けて操作できる。
- 作業後にdata/products.jsonの差分がない。

## 機能ブランチのテスト

feature/searchではtests/test_search.py、feature/sortではtests/test_sorting.pyが加わります。統合後は両方のテストを残してください。配布時のmainは5件、検索ブランチは9件、並べ替えブランチは8件です。両方を統合すると配布テストは12件になります。メニューの統合は、実際の入力でも確認します。

# 基本の操作

main.pyがあるフォルダーで起動します。メニューでは次の操作を選べます。

- `1`: JSONに記録された順番で商品一覧を表示する
- `2`: 商品名の一部で検索する。検索キーワードの前後の空白は無視します
- `3`: 価格が安い順に商品一覧を表示する
- `0`: 終了する

それ以外の入力では案内を表示し、メニューへ戻ります。

一覧の1行目は次のようになります。

```text
1 | ノート | 文房具 | 250円 | 在庫 8個
```

検索や並べ替えを行っても、元の商品一覧とJSONの順番は変わりません。商品一覧を開く操作では、JSONの内容を保存し直しません。プログラムを終了して再起動しても、配布データが変わらないことを確認します。

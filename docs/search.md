# 商品名の検索

feature/searchに実装された機能です。

- search.pyのsearch_products(products, keyword)を使います。
- キーワードの前後の空白を取り除きます。
- キーワードが商品名の一部に含まれる商品を返します。
- 一致した商品の順番は元の一覧と同じです。
- 空のキーワードや該当商品がない場合は空のリストを返します。
- main.pyでは該当商品がないことを日本語で表示します。
- 元の商品リストとJSONは変更しません。

配布データで「ペン」はボールペン1件、「ノート」はノート1件に一致します。「電池」と空の入力は該当なしです。

検索ブランチではメニュー2を使います。統合後は、価格順の表示と別の番号にしてください。

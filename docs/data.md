# 商品データ

data/products.jsonは、架空の店舗の商品10件を記録したJSON配列です。各要素をProductに変換して読み込みます。価格は円、stockは現在ある商品の個数です。

| キー | Pythonで扱う型 | 内容 |
| --- | --- | --- |
| id | int | 商品番号 |
| name | str | 商品名 |
| category | str | 文房具、飲料、日用品 |
| price | int | 1個の価格 |
| stock | int | 在庫数。0も含む |
